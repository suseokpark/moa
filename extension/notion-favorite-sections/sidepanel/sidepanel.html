사용 안내

보관함 검색은 제목·URL·상위 그룹 경로에서 단어를 찾습니다. 단어를 띄어 쓰면 순서·대소문자와 관계없이 모든 단어를 포함한 링크를 보여줍니다. 예: ‘디자인 가이드’와 ‘가이드 디자인’. 그룹 경로에 모든 단어가 있으면 그 아래 링크도 표시합니다. 따옴표·특수문자도 글자 그대로 검색하며 검색을 지우면 저장된 접힘 상태로 돌아갑니다. 열린 탭·북마크 가져오기 창의 검색 방식은 기존과 같습니다.

그룹 옆 +에서 링크와 하위 그룹을 추가하세요. 그룹 메뉴에서 하위 내용 전체를 다른 그룹으로 옮길 수 있습니다.

보관함 선택기에서 다른 보관함을 고르면 검색·임시 보기 상태·선택 모드를 정리하되 저장된 그룹 접힘과 되돌리기는 유지하며, 같은 보관함을 다시 고르면 현재 화면을 유지합니다.

그룹의 ⋯ → 그룹 색상에서 표식·연결선과 연한 배경색을 바꿀 수 있어요. 같은 그룹의 제목과 링크가 한 색으로 묶이고, 하위 그룹은 각각 따로 표시됩니다. 기본 색상으로 되돌릴 수도 있습니다.

로그인 없이 이 브라우저에 저장합니다. 기기 간 이동은 JSON 백업을 이용하세요. 그룹 색상이 포함된 백업은 0.1.21 이상에서 불러오세요. 색상은 백업에 포함되지만 전체 테마는 이 브라우저에만 저장됩니다.

링크를 누르면 이미 열린 탭으로 이동합니다. 새 탭은 링크 메뉴에서 선택하세요.

링크 추가·단일 링크 이동·그룹 메뉴 이동·드래그 이동이 성공하면 목적지 경로를 펼치고 검색을 지운 뒤 결과를 보여줍니다. 옮긴 그룹 자체의 접힘은 유지합니다. 되돌리기는 편집과 자동 펼침을 함께 취소하며, 이후 직접 바꾼 접힘 상태는 유지합니다. 취소·실패·검토만으로 검색과 접힘을 바꾸지 않고 동일 위치 이동은 저장하지 않습니다.

링크 추가·수정·단일 링크 이동 중 충돌하면 ‘입력 유지하고 최신 목록 검토’로 작성한 값을 유지하며 최신 목록을 확인하세요. 대상 링크의 내용·위치가 바뀌었다면 최신 값을 검토하고 명시적으로 확인한 뒤 따로 저장합니다. 삭제된 기존 링크·보관함은 자동 재생성하지 않으며, 새 링크의 목적지가 사라졌다면 직접 다시 고릅니다. 검토만으로 저장하거나 자동으로 덮어쓰지 않습니다.

열린 탭·북마크를 담다가 저장 충돌이 나면 ‘선택 유지하고 최신 목록 검토’로 선택을 유지한 채 바뀐 보관함을 검토하세요. 이미 저장된 선택의 제외 개수를 확인하고 삭제된 목적지는 직접 다시 고른 뒤 담기를 누르세요. 확인만으로 저장하거나 원본 탭·북마크를 다시 읽지 않습니다. 이름·그룹색·그룹 이동·일괄 이동의 충돌 복구도 지원하며, 최신 내용을 확인한 뒤 따로 저장합니다.

링크 삭제·그룹 삭제·현재 보관함 초기화 중 충돌하면 최신 영향 범위를 검토하세요. 그룹 삭제는 내용을 지우지 않고 보존할 위치를 보여줍니다. 충돌 뒤에는 변경 유무와 관계없이 명시적으로 확인한 뒤 삭제·초기화를 따로 눌러야 합니다. 삭제된 원래 대상·보관함은 다른 것으로 바꾸지 않습니다. JSON 복원은 충돌해도 선택한 파일을 유지하고 최신 현재 목록과 기존 안전 사본에 미치는 영향을 검토한 뒤 별도로 실행합니다. 복원 전 목록 복구는 실제 사본을 읽어 미리 보고 명시적으로 확인한 뒤 따로 실행하며, 사본이 없거나 손상되면 중단합니다. 검토만으로 목록을 바꾸지 않습니다. 기존 Moa 가져오기 충돌 시에는 최신 저장 목록만 검토하고 명시적으로 확인한 뒤 별도로 가져옵니다. 원본은 실제 가져오기 시점에 읽으며 검토로 원본을 미리 보거나 고정하지 않습니다. 현재 목록의 이전 기록으로 중복을 막고 추가 0개라도 경고가 있으면 확인이 필요한 결과로 안내합니다.

0.1.19부터 Notion 내부 메뉴는 제공하지 않습니다. 기존 목록은 삭제하지 않으며, 필요하면 ‘기존 Moa 목록 가져오기’로 복사할 수 있습니다. Notion 페이지와 Drive 폴더는 일반 링크로 담아 원본에서 열 수 있습니다. Google 연결·자동 동기화는 이번 버전에서 제공하지 않습니다.

되돌리기는 마지막 내용 편집 1회만 취소합니다. 그룹을 접거나 펼쳐도 이 기회는 사라지지 않으며, 직접 바꾼 접힘 상태는 유지합니다. 여러 단계 되돌리기는 지원하지 않습니다. 복원 전 안전 사본은 별도로 유지됩니다.
