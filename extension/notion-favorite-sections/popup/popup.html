FAVMOA 팹모아

버전 0.1.36

자주 찾는 링크를 한곳에, 팹모아.

0.1.10 이하에서 처음 옮길 때는 별도 폴더에 설치하세요. 이전 확장에서 목록을 JSON으로 내보낸 뒤 새 확장에서 가져오세요. 이전 확장은 삭제하거나 초기화하지 마세요. 0.1.9 사용자는 원래 폴더에서 키 없는 0.1.10으로 먼저 업데이트하고 ‘기존 Moa 목록 가져오기’를 실행한 뒤 내보내세요.

로그인 없이 이 Chrome 프로필에 링크를 저장합니다. 다른 기기로 옮기거나 보관하려면 JSON 내보내기·가져오기를 사용하세요. Google 연결과 클라우드 백업은 준비 중입니다.

0.1.11부터는 공개키로 확장 ID를 고정했습니다. 컴퓨터와 설치 폴더가 달라도 같은 ID지만, 로컬 데이터가 자동으로 복사되지는 않습니다.

0.1.11~0.1.35를 설치했다면 먼저 JSON 백업을 저장한 뒤 같은 폴더의 파일을 0.1.36으로 교체하고 확장 카드를 새로고침하세요. 공개키·확장 ID는 바뀌지 않았습니다.

상단 테마에서 나에게 맞는 색을 고르세요. 시스템 설정·밝게·어둡게 모드와 여섯 가지 색상 조합을 제공하며, 강조색과 밝은 화면·어두운 화면의 배경색을 직접 지정할 수 있습니다. 미리 본 뒤 저장하면 적용되고 취소하면 원래 테마로 돌아갑니다.

0.1.36에서는 기존 Moa 가져오기 충돌 뒤 최신 저장 목록을 검토합니다. 오래된 가져오기를 반복하지 않고 최신 대상 목록을 읽어 확인한 뒤, 명시적 확인과 별도 가져오기 버튼으로 다시 실행합니다. 원본은 실제 가져올 때 읽으며 이 검토는 원본 미리보기나 고정이 아닙니다. 현재 목록의 이전 기록으로 중복을 막고, 가져온 목록이 없어도 경고가 있으면 확인이 필요한 결과로 안내합니다.

0.1.35의 JSON 복원과 복원 전 목록 복구 미리보기도 유지합니다. JSON 충돌 뒤에도 선택한 파일은 유지하고 최신 현재 목록과 기존 안전 사본에 미치는 영향을 다시 확인합니다. 복원 전 목록 복구는 실제 안전 사본을 읽어 미리 보고 명시적으로 확인한 뒤 별도로 실행합니다. 읽기·검토만으로 저장하지 않으며 사본이 없거나 손상되면 복구를 막습니다.

0.1.34의 링크 삭제·그룹 삭제·현재 보관함 초기화 충돌 복구도 유지합니다. 원래 대상과 최신 영향 범위, 그룹 내용의 보존 위치를 검토하고 명시적으로 확인한 뒤 별도로 실행합니다. 삭제된 원래 대상·보관함을 다른 것으로 대체하지 않습니다.

0.1.33의 그룹 이동·일괄 링크 이동 중 원래 이동 대상과 목적지 선택 보존도 유지합니다. 최신 목록을 검토해 이동할 하위 트리·링크와 목적지 경로의 변화를 확인한 뒤 별도로 이동하세요. 삭제된 출발 그룹·선택 링크·보관함은 다른 대상으로 바꾸거나 일부만 이동하지 않습니다. 사라졌거나 이동할 수 없어진 목적지는 직접 다시 선택해야 합니다. 검토만으로 이동하지 않습니다.

0.1.32의 보관함·그룹 추가와 이름 변경, 그룹 색상 변경 중 입력 보존도 유지합니다. ‘입력 유지하고 최신 목록 검토’로 최신 이름·색상·경로를 확인하세요. 대상이 바뀌었다면 명시적으로 확인한 뒤 별도로 저장해야 합니다. 삭제된 보관함·그룹·상위 그룹은 자동 재생성하거나 다른 위치로 바꾸지 않으며, 입력을 복사하거나 취소할 수 있습니다. 새 보관함 추가는 이전 보관함의 삭제와 무관하게 검토 후 저장할 수 있습니다.

0.1.31의 링크 추가·수정과 단일 링크 이동의 입력 보존도 유지합니다. ‘입력 유지하고 최신 목록 검토’로 최신 저장 목록을 읽어 확인하세요. 대상 링크의 내용·위치가 바뀌었다면 최신 값을 검토하고 명시적으로 확인한 뒤 별도로 저장해야 합니다. 삭제된 기존 링크·보관함은 자동 재생성하지 않고, 새 링크의 목적지가 사라졌다면 직접 다시 고릅니다. 검토만으로 저장하거나 변경을 자동으로 덮어쓰지 않습니다.

0.1.30의 열린 탭·북마크 선택 보존도 유지합니다. ‘선택 유지하고 최신 목록 검토’를 눌러 바뀐 보관함을 검토하고 저장할 항목과 위치를 확인한 뒤 다시 담으세요. 확인만으로 저장하지 않습니다. 이미 저장된 선택은 제외 개수를 알려주고, 삭제된 보관함·그룹은 새 목적지를 직접 선택해야 합니다. 탭·북마크 원본을 다시 읽거나 북마크 권한을 다시 요청하지 않습니다.

0.1.29의 되돌리기 보호도 유지합니다. 링크 추가·이동·이름이나 색상 변경 등 마지막 내용 편집 1회를 취소할 수 있습니다. 그룹을 접거나 펼쳐도 이 기회는 유지하고, 편집 뒤 직접 바꾼 접힘 상태도 유지합니다. 접기·펼치기 자체는 되돌리기 대상이 아니며, 여러 단계의 편집 이력을 제공하는 기능은 아닙니다.

0.1.28의 북마크 가져오기 개선도 유지합니다. 제목·주소·원래 폴더 경로로 검색하고 ‘보이는 북마크 모두 선택’으로 필요한 항목을 고르세요. 목록은 200개씩 더 볼 수 있고 한 번에 최대 1,000개를 담습니다. 검색 밖 선택도 개수로 알려주며, ‘선택 해제’는 검색어를 유지한 채 숨겨진 선택까지 모두 해제합니다. 선택이 없으면 담기 버튼을 누를 수 없습니다. 읽는 중 취소할 수 있고 늦게 도착한 목록이 다른 작업창을 덮지 않습니다. 저장한 그룹을 바로 보여주며 한 번의 되돌리기로 추가 전체를 취소합니다. 북마크 권한은 가져오기를 직접 눌렀을 때만 요청하고 원본 북마크는 변경하지 않습니다.

0.1.27의 열린 탭 담기도 유지하며 같은 검색·선택·선택 해제 흐름을 사용합니다. 일반 Chrome 창의 웹 탭 중 시크릿 탭·이미 저장한 링크·중복 탭은 제외합니다. 원래 탭을 닫거나 이동하지 않으며, 새 탭을 반영하려면 대화상자를 닫고 다시 여세요. 추가 권한·로그인·클라우드 연결은 필요하지 않습니다.

0.1.26의 선택 → 선택 이동…으로 여러 저장 링크를 한 번에 옮기는 기능도 유지합니다. 일반 링크 클릭·첫 클릭 보호·테마 색상과 기존 데이터는 그대로입니다.

0.1.19부터 Chrome 사이드 패널 하나만 사용합니다. Notion 안의 FAVMOA 메뉴와 전용 화면은 종료했습니다. 기존 Notion 탭을 새로고침하면 남아 있는 내부 메뉴가 사라집니다. Notion 페이지는 다른 사이트처럼 링크로 담고 열 수 있습니다.

이제 그룹 안에 하위 그룹과 링크를 함께 넣을 수 있습니다. 기존 사용자 섹션은 하위 그룹으로, 자동 미분류 섹션의 링크는 부모 그룹으로 옮겨집니다. 이전 JSON 백업도 불러올 수 있지만 새 형식의 백업은 0.1.15 이하에서 읽을 수 없습니다. 업데이트 전 백업은 따로 보관하세요.

FAVMOA 링크 보관함 열기 ↗

링크 보관함 사용 방법

  1. Chrome 도구 모음의 FAVMOA 아이콘을 누르면 어느 사이트에서든 사이드 패널이 열립니다.
  2. 그룹과 그 안의 하위 그룹을 만들고, 원하는 그룹에 현재 페이지 또는 직접 입력한 링크를 추가합니다.
  3. 열린 탭 담기에서 필요한 웹 탭만 고르고 저장 그룹을 지정합니다. 탭은 열린 채로 두고 링크만 복사합니다.
  4. 그룹을 접거나 펼치고, 이동 메뉴로 하위 그룹과 링크를 함께 옮길 수 있습니다. 자기 자신이나 자손 그룹 안으로는 옮길 수 없습니다.
  5. 열린 링크를 누르면 기존 탭으로 이동합니다. 새 탭으로 열기도 선택할 수 있습니다.
  6. 북마크 가져오기는 권한 승인 후 검색·전체 선택·선택 해제로 필요한 항목만 고르고 그룹에 복사합니다. 원본 북마크는 바꾸지 않습니다.
  7. 백업 · 가져오기 · 설정에서 JSON으로 내보내거나 백업 파일을 가져올 수 있습니다. 복원할 목록을 먼저 확인한 뒤 적용하세요.
  8. 상단 테마에서 색상 선택기나 HEX 값으로 색을 정합니다. 기본 테마로는 미리보기만 초기값으로 바꾸며 저장해야 확정됩니다. 링크와 그룹은 바뀌지 않습니다.
  9. 그룹의 더보기 → 그룹 색상에서 색을 고르고 저장합니다. 기본 색상도 저장해야 확정되고, 취소하면 기존 색을 유지합니다. 미분류 그룹도 색을 정할 수 있습니다.

이전 Notion 목록은 남겨 두었습니다

Notion 전용 화면 종료가 기존 데이터 삭제를 뜻하지는 않습니다. 필요할 때 백업 · 가져오기 · 설정 → 기존 Moa 목록 가져오기로 이 확장에 저장된 목록을 새 보관함에 복사하세요. 자동 이전은 하지 않습니다.

Notion 즐겨찾기와 하위 페이지를 새로 읽어오는 기능은 제공하지 않습니다. 원본 페이지를 연 뒤 Chrome 사이드 패널의 이 페이지 담기로 추가할 수 있습니다.

업데이트 후에도 Notion 메뉴가 남아 있나요?

Chrome 확장 관리 화면에서 FAVMOA를 새로고침한 뒤, 열려 있던 Notion 탭도 새로고침하세요. 이후에는 Chrome 도구 모음의 FAVMOA 아이콘으로 보관함을 엽니다.

이전 목록이 다른 확장 ID나 Chrome 프로필에 저장되어 있으면 여기서 직접 읽을 수 없습니다. 원래 설치에서 JSON 백업을 만든 뒤 가져오세요. 목록 확인 전에는 원래 확장을 삭제하거나 초기화하지 마세요.

저장 범위와 권한

  • 보관함은 이 Chrome 프로필의 확장 로컬 저장소에 저장합니다. 이 버전은 Google 로그인이나 클라우드 전송을 실행하지 않습니다.
  • 테마도 이 Chrome 프로필에만 따로 저장합니다. 링크 JSON 백업에는 테마가 포함되지 않으며, 목록 복원이나 초기화로 테마가 바뀌지 않습니다.
  • 그룹 색상은 테마와 달리 보관함에 저장되어 JSON 백업과 되돌리기에 포함됩니다. 색상이 포함된 백업은 0.1.21 이상에서 열어야 합니다. 이전의 색상 없는 백업은 계속 불러올 수 있습니다.
  • 비공개 원본 문서를 열려면 해당 서비스의 로그인과 접근 권한이 필요합니다.
  • 기존 Moa 가져오기는 저장된 트리를 새 그룹 구조로 변환한 복사본을 만듭니다. 종료된 Notion 전용 화면의 원본 저장소를 지우거나 자동 이전하지 않습니다.
  • JSON 백업 복원은 전체 보관함을 교체합니다. 먼저 내보내기로 보관하고 확인하세요. 가져올 파일은 6MiB, 내부 보관함 데이터는 5MiB까지입니다.
  • 자동 기기 간 병합 동기화는 아직 지원하지 않습니다. 확장을 제거하면 로컬 데이터가 지워질 수 있으므로 먼저 백업하세요.
  • FAVMOA에서 제거해도 Notion 페이지·Drive 파일·Chrome 북마크 원본은 유지됩니다. 페이지 본문이나 서비스 로그인 쿠키는 수집하지 않습니다.
