버전 0.1.9

자주 찾는 페이지를 한곳에 모아.

Notion 열기 ↗

사용 방법

  1. Notion의 왼쪽 사이드바와 즐겨찾기를 펼칩니다.
  2. 수신함 옆 청록색 책갈피 아이콘이 있는 Moa를 누릅니다.
  3. + 즐겨찾기에서 검색하고 항목을 체크한 뒤, 담을 그룹·섹션을 골라 추가합니다.
  4. 그룹과 섹션의 화살표로 접고 펼칩니다. 페이지의 메뉴에서 위치를 바꿀 수 있습니다.
  5. 현재 열린 페이지와 하위 페이지를 확인하고, 제목을 눌러 이동합니다. 하위 트리는 Notion 사이드바에 로드된 항목만 표시합니다.

항목이 보이지 않나요?

Moa를 닫고 Notion 즐겨찾기를 펼친 뒤 다시 열어 보세요. 현재 사이드바에 표시된 항목만 추가할 수 있습니다. 목록 갱신은 이미 담은 항목을 확인하며, 새 항목은 직접 추가합니다.

이전 버전에서 제목 대신 ID가 보인다면 원본 즐겨찾기를 한 번 펼친 뒤 목록을 갱신하세요. 기존 그룹·섹션은 그대로 두고 제목을 복구합니다.

내 브라우저에 저장

  • 별도 로그인 없이 사용하며, 정리한 트리는 워크스페이스별로 이 브라우저에 저장됩니다.
  • 담아 둔 즐겨찾기의 제목·이모지 아이콘도 보관해 원본 목록이 접혀 있어도 이름을 보여 줍니다.
  • 다른 기기로 자동 동기화되지 않습니다. 확장을 제거하면 로컬 데이터가 지워질 수 있습니다.
  • Moa에서 제거하거나 초기화해도 Notion의 원본 즐겨찾기는 유지됩니다.
  • 페이지 본문과 로그인 정보는 읽지 않으며, 외부로 데이터를 전송하지 않습니다.
