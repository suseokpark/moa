# FAVMOA 0.1.26 QA — 여러 링크 선택 후 일괄 이동

검증일: 2026-09-23 KST. 0.1.25 → 0.1.26, 다음 패치 0.1.27.

## 사용 방법과 범위

1. 목록 위 **선택**을 누른다. 선택 모드에서만 체크박스가 보이며 제목을 눌러도 페이지를 열지 않는다.
2. 원하는 링크를 고르거나 **보이는 링크 모두 선택**을 사용한다. 현재 검색 결과와 펼쳐진 그룹의 실제 표시 항목만 전체 선택/해제한다.
3. **선택 이동…**에서 목적지 그룹과 이동 개수를 확인하고 **이동**한다. 직후 **되돌리기** 한 번으로 전체 이동을 복구한다.

선택은 검색·접기·탭 갱신 사이에 유지한다. 숨겨진 선택은 개수와 확인 문구로 알린다. 보관함 변경·선택 종료·패널 재시작 시 선택 모드는 끝난다. 링크 선택은 저장/백업에 포함하지 않는 임시 상태다. 선택 중에는 링크·그룹 드래그와 행 메뉴를 잠시 숨기며 일반 모드의 클릭·드래그는 유지한다.

이번 기능은 같은 보관함 안의 링크 이동이다. 여러 링크 삭제, 그룹 다중 선택, 보관함 간 이동, 자동 동기화는 추가하지 않았다. 기존 schema 2·저장 키·권한·고정 ID를 유지한다.

## 데이터 보호

- `moveLinks` 하나로 모든 대상과 목적지를 검증한 뒤 한 번의 저장·revision 증가·undo를 수행한다. 하나라도 유효하지 않으면 부분 이동하지 않는다.
- 기존 트리 순서대로 목적지 끝에 추가한다. 이미 목적지에 있는 항목은 원래 자리를 유지하며, 모든 항목이 이미 목적지이면 revision·이전 undo·접힘 상태도 바꾸지 않는다.
- 실제 이동 시 목적지와 상위 그룹을 함께 펼친다. 되돌리기는 이동 전 위치·순서·접힘 상태를 함께 복구한다.
- 이동 확인창은 보관함·선택 ID·revision을 캡처한다. 충돌이면 최신 목록을 반영하고 사라진 선택만 정리하며 유효 선택·검색·확인창을 보존한다. 조용히 일부만 옮기지 않는다.
- 이동 확인 취소는 데이터와 선택을 바꾸지 않는다. 같은 그룹만 선택한 확인창의 비활성 제출 상태가 다음 추가/편집 양식에 남지 않도록 초기화한다.
