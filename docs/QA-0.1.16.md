- localhost 합성 데이터로 그룹·하위 그룹·링크 혼합 구조, 이동·되돌리기·검색·현재 위치·키보드 초점을 확인했다.

## 자동 검사

저장소 루트에서 `npm test`를 새로 실행하고 최종 소스에서 반복 확인했다. 두 실행 모두 367개 통과, 실패 0개다. 이전 릴리스 숫자를 재사용하지 않았다.

주요 검증 경계:

- [재귀 모델 검사](../extension/notion-favorite-sections/test/link-library-recursive.test.mjs): 사용자 섹션/자동 섹션 구분, ID 충돌의 결정적 변환, 직접 링크와 하위 그룹, 순환 구조 차단, 32단계 경계, 삭제 후 내용 보존.
- [schema 이전 저장 계약](../extension/notion-favorite-sections/test/catalog-schema-migration.test.mjs): GET/no-op 무기록, 첫 실제 변경의 원형 보관, 저장 실패·동시 쓰기·오래된 revision 보호, 구형 undo·복원 사본, 구형 JSON 가져오기.
- [재귀 패널 검사](../extension/notion-favorite-sections/test/sidepanel-recursive.test.mjs): 검색의 조상 경로와 중복 없는 개수, 현재 페이지 펼침, 안전한 이동 목적지, 검색 중 저장된 접힘 불변, 다시 그린 화면의 초점 복구.
- 기존 링크 안전성·권한·Notion 저장 계약·브랜드·패키지 검사도 전체 실행에 포함한다. 보존된 Google 코드의 모의 검사 통과는 실제 Google 연결 증거가 아니다.

Node 검사는 데이터·서비스·화면 계약을 검증한 것이며 실제 설치 업데이트나 브라우저 파일 선택 업로드를 대신하지 않는다.

## localhost 합성 브라우저 흐름

실제 설치 확장과 다른 localhost 미리보기 저장소에서 확인했다. 사용자의 실제 링크나 계정 데이터는 조작하지 않았다.

| 흐름 | 관찰 결과 |
|---|---|
| 기존 합성 schema 1 열기 | 기존 링크 3개와 이름을 유지한 채 새 그룹 모델로 표시 |
| 하위 그룹 생성 + 직접 주소 추가 | 하위 그룹을 만들고 링크를 직접 저장하여 전체 4개가 됨 |
| 깊은 링크 검색 | 조상 그룹 경로가 함께 표시되고 일치 개수가 전체 4개 중 1개로 표시 |
| 검색 중 접힘 | 접기 조작은 비활성화되어 저장된 접힘을 바꾸지 않음. 검색을 지우면 원래 접힘 복원 |
| 현재 링크를 3단계 경로로 이동 | 표시 경로와 해당 링크의 초점이 새 위치에 맞게 갱신 |
| 프로젝트 하위 트리를 최상위로 이동 | 전체 링크 4개를 보존하고 되돌리기로 이전 위치 복구 |
| 이름 변경·비모달 순서 변경 | 다시 그려진 화면에서 조작 대상의 초점 유지 |
| Escape | 대화상자를 닫은 뒤 적절한 조작 대상으로 초점 복귀 |
| 360px 밝은 화면 / 320px 어두운 화면 | 가로 넘침 없음. 제목·검색·이동 선택기를 조작 가능 |
| 사이드 패널 콘솔 | 확인한 흐름에서 경고·오류 0건 |

검사 후 화면 크기·색상 모드 재정의를 해제했다. 원래 2056×1169의 밝은 화면에서 가로 넘침 없이 3단계 현재 경로가 보이는 것을 확인하고 미리보기를 남겼다.

## 구형 Notion 합성 회귀와 간헐 실패

`test/browser-suite.html` 최초 실행은 **7/8**이었다. 사용성 fixture의 짧은 메뉴 검사에서 **`Last action cannot be reached`**가 발생했다. 이후 해당 사용성 검사를 개별 실행한 결과 **19/19**, 전체 suite 재실행은 **8/8**이었다.

타이밍 또는 메뉴 위치 재계산과 연관되었을 가능성은 있으나 **원인을 확정하지 않았다**. 재실행 성공은 최초 실패가 없었다는 뜻도, 문제가 고쳐졌다는 뜻도 아니다. 이번 작업에서 구형 Notion 런타임을 변경하지 않았으며 이 항목은 간헐 실패로 기록한다. 실제 Notion 계정에서의 검증도 수행하지 않았다.

## 남은 검증과 사용자 주의

- 실제 설치 확장의 저장소 이전·기존 열린 탭 연결·설치 갱신은 localhost 합성 검증과 별개이며 미검증이다.
- 브라우저 파일 선택을 통한 JSON 업로드·다운로드 파일의 실제 왕복은 미검증이다. 자동 검사의 JSON/서비스 계약 통과와 구분한다.
- Google 로그인·Drive 동기화·다른 PC의 원격 복원은 이번 범위가 아니며 시도하지 않았다.
- 0.1.16은 이전 schema 1 JSON을 읽지만 **0.1.15 이하에서는 새 schema 2 JSON을 읽을 수 없다**. 업데이트 전 버전에서 JSON 백업을 별도 파일로 남겨야 한다.
- 새 형식 저장소 위에 구형 코드를 덮어쓰는 다운그레이드를 지원하지 않는다. 내부 원형 사본과 일반 되돌리기는 외부 파일 백업이나 앱 버전 복귀를 대신하지 않는다.
