# FAVMOA 0.1.43 · 가져오기 선택 항목 검토

검증일: 2026-09-25 KST. 사용자의 ‘다음 개선 사항 적용’ 요청에 따라 선택한 항목 모아보기를 구현했다. 완료된 감사 큐를 다시 열거나 중지된 자동화를 재개하지 않았다.

## 변경과 재현

- 탭·북마크 가져오기에 `선택한 항목만 보기` 토글을 추가했다. 버튼 부재를 신규 기능 회귀 8개의 실패로 확인한 뒤 구현했다. 검색 조건과 관계없이 선택 항목을 모으며, 검토 중 검색은 비활성화하고 같은 버튼을 다시 누르면 원래 검색어·표시 범위를 복원한다.
- `aria-pressed`와 보이는 도움말로 현재 모드·복귀 방법을 설명한다. 선택 해제 시 해당 행을 제거하고 다음/이전 체크박스, 마지막 항목이면 보기 전환 버튼으로 초점을 옮긴다. 전체 해제도 빈 검토 화면과 돌아갈 경로를 유지한다.
- 검색·선택 보기마다 별도의 200개 표시 범위를 사용하며 최대 1,000개 선택 정책을 유지한다. 새 그룹 이름·위치와 기존 목적지를 보존한다. 보기 전환/선택 해제는 후보 재조회·저장·revision·Undo 변경을 만들지 않는다.
- 독립 경계 검토에서 201번째 항목을 연 뒤 숨겨진 `더 보기`에 초점이 남는 문제를 재현했다. 일반/선택 보기 모두 새로 표시된 첫 체크박스로 이어지도록 수정하고 회귀를 추가했다. 더 보기 방식 자체나 다단계 Undo는 재설계하지 않았다.
- 380×820 예시 브라우저에서 하단 고정 액션이 `새 그룹에 담기`를 가리고, 해당 버튼에 초점이 있어도 액션 아래에 남는 것을 확인했다. 가져오기 창에만 헤더·액션 사이 별도 스크롤을 적용했다. 수정 후 실제 클릭 성공 및 320×640에서 입력 초점이 본문 안에 있고 액션과 겹치지 않음을 확인했다. 다른 대화상자에는 적용하지 않는다.
- 저장 모델·권한·확장 ID·원본 북마크/탭은 변경하지 않았다.
