# FAVMOA 0.1.42 · 가져오기 검색 통일

검증일: 2026-09-25 KST. 등록 개선 후보 1~7 완료 뒤 사용자가 별도로 승인한 후속 변경이다. 중지된 반복 자동화는 재개하지 않는다.

## 재현과 구현

- TDD 스킬에 따라 실제 배포 picker 핸들러의 모의 DOM에서 `디자인 가이드`는 보이지만 `가이드 디자인`은 0개인 RED를 확인한 뒤 수정했다. 검색 안내/접근성 설명 부재도 RED→GREEN으로 검증했다.
- 탭·북마크 검색을 공백 단위 모든 단어(AND), 순서·대소문자 독립 방식으로 통일했다. 제목·URL·원본 북마크 폴더 경로 중 어느 필드든 같은 후보 안에서 모든 단어가 맞아야 한다. 서로 다른 후보의 단어를 합치지 않는다.
- 중복 단어를 한 번 계산하고 빈/공백 검색은 기존 순서로 전체 결과를 보여준다. 따옴표·정규식·OR·제외 연산자·유사어·URL 디코딩은 추가하지 않으며 특수문자는 문자 그대로 검색한다.
- 검색 입력에 보이는 짧은 설명과 `aria-describedby` 연결을 추가했다. 기존 메인 트리 검색·저장 모델·revision·한 단계 Undo·권한·확장 ID는 변경하지 않았다.
- 검색 변경에 원본 탭/북마크 재조회나 저장이 없다. 기존 목적지·숨은 선택·새 그룹 이름/위치를 보존하며, 200개 표시·전체 결과 선택·1,000개 합집합 제한·충돌 뒤 최신 검토 계약을 유지한다.
- 이전 회귀의 ‘후보 창은 문구 검색 유지’ 1개는 승인된 계약 변경에 따라 순서 독립 기대값으로 갱신했다. 원본 0.1.28 감사와 과거 버전 QA는 수정하지 않았다.
