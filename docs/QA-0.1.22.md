# FAVMOA 0.1.22 QA — 같은 그룹의 연한 배경

기록일: 2026-09-23 KST. 이번 버전에서 실행한 증거만 기록하며 코드·합성 검증과 실제 Chrome 사용을 구분한다.

## 변경 범위

- 그룹 제목과 직접 속한 링크를 지정한 그룹색의 연한 배경으로 감싼다. 색상 표식·연결선과 기존 색상 편집 흐름은 유지한다.
- 기본 테마 배경에 그룹색을 최대 8% 섞어 불투명한 배경을 계산한다. 글자·상태·포커스 대비가 부족해지면 농도를 줄인다.
- 하위 그룹은 각자의 색을 사용하고 지정색이 없으면 기본 배경을 사용한다. 부모 배경과 투명하게 겹치지 않아 중첩에 따라 농도가 누적되지 않는다.
- 접힘·검색·현재 열린 링크·키보드 포커스·메뉴를 유지한다. 설정 항목·데이터 필드·저장 기록·권한을 추가하지 않는다.
- schema 2·고정 확장 ID·공개키·JSON 백업 호환성과 Notion 내부 UI 종료·Google 연동 보류를 유지한다.

## 수용 기준

1. 지정색이 있는 그룹은 제목부터 직접 속한 마지막 링크까지 하나의 연한 배경으로 연결된다.
2. 상위·하위 그룹은 각각의 색을 사용하고, 지정색이 없는 하위 그룹은 기본 배경을 유지한다. 깊이에 따라 같은 색이 계속 진해지지 않는다.
3. 밝음·어두움·사용자 지정 배경에서 텍스트·열림 표시·포커스가 읽히도록 농도를 조절한다. 현재 링크 강조는 그룹 배경과 구분된다.
4. 그룹을 접거나 검색해도 배경이 그룹 범위를 벗어나지 않으며 메뉴와 포커스를 자르지 않는다.
5. 기존 그룹색 변경·취소·기본색 복구·되돌리기로 배경도 반영되고, 그룹 구조·링크·저장 계약은 변경하지 않는다.

- Node·모의 DOM·localhost 검사는 실제 Chrome 사용자 저장소·OS 색상 선택기·다른 PC 동작을 대신하지 않는다.
