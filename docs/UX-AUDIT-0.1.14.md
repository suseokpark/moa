# FAVMOA 0.1.14 사용성 점검

## 범위와 기준

2026-09-23, Chrome에서 저장소의 로컬 미리보기를 360px 사이드패널 폭으로 점검했다. 실제 확장 주소의 자동 접근은 도구 보안 정책상 제한되어 있으므로 우회하지 않았다. 예시 데이터만 사용했으며 실제 확장의 링크, 계정, 저장소는 변경하지 않았다. Google 로그인·Drive 연동은 이번 릴리스에서 보류한다.

목표: 처음 사용하는 사람이 주소를 담고, 그룹·섹션에서 찾고, JSON으로 안전하게 이동·복구할 수 있어야 한다. 기존 브랜드와 2단계 폴딩 구조를 유지한다. 스크린샷은 이 점검 중 직접 캡처하고 저장한 동일 파일을 열어 확인했다.

## 변경 전 관찰

1. **첫 화면 — 단순화 필요.** 현재 페이지와 빈 상태 안내는 분명하지만 `연결·백업`, `Google 백업은 선택`, `로그인은 나중에`가 로컬 전용 결정과 충돌한다. `+ 링크`와 `첫 링크 담기`의 동작 차이도 모호하다. [화면](../artifacts/qa-0.1.14/01-before-start.jpg)
2. **백업 진입 — 우선순위 개선 필요.** 상단 바로가기가 Google 영역으로 이동한다. 실제 사용할 파일 백업 앞에 비활성 Google 버튼 네 개가 놓이고, 긴 안내가 좁은 화면을 차지한다. JSON 백업을 상단의 직접 목적지로 바꾼다. [화면](../artifacts/qa-0.1.14/02-before-backup.jpg)
3. **링크 추가 — 입력 부담 개선 필요.** 이름을 먼저 필수 입력하고 주소·그룹·섹션을 동시에 보여준다. 주소 우선, 이름 선택, 저장 위치 접기로 시작 단계를 줄인다. 입력 라벨과 초점 테두리는 유지한다. [화면](../artifacts/qa-0.1.14/03-before-add.jpg)

## 제안하고 구현한 개선

- 로컬 저장·JSON 백업 중심으로 메뉴와 안내 통일. 보류한 Google UI와 실행 경로는 비활성화하고 불필요한 인증 권한을 배포본에서 제외.
- URL 우선 입력, 도메인만 붙여넣어도 HTTPS 주소로 정규화. 이름을 생략하면 도메인명 사용. 네트워크로 제목을 수집하지 않음.
- 기본 저장 위치를 요약하고, 위치를 변경할 때만 그룹·섹션 선택을 펼침.
- 복원 직전의 전체 목록을 일반 1회 되돌리기와 별도로 보관. 이후 편집·접기에도 안전 사본을 유지하고 명시적 확인 후 복구.
- 검색 지우기/Escape, 데이터 교체 미리보기와 취소, 좁은 화면·키보드 회귀 검증.

## 증거 한계

실제 Chrome 확장의 탭 권한·북마크 권한·설치 갱신은 이 자동화에서 검증하지 못한다. 로컬 미리보기 결과와 순수 모델·계약 테스트 결과를 별도로 기록한다. 전체 WCAG 적합성이나 실제 스크린리더 호환성을 주장하지 않는다.

## 사용자 스토리와 확인 결과

1. **처음 쓰는 사용자**는 로그인 없이 주소 하나만 입력해 저장하고 싶다. 도메인 입력 → 이름 생략 → HTTPS 링크 1개 생성 통과. 입력창에 주소가 먼저 초점되고 중복·잘못된 주소는 입력을 유지하며 차단한다.
2. **정리하는 사용자**는 분류가 필요할 때만 선택하고 싶다. 접힌 저장 위치를 펼쳐 `업무 자료 / 프로젝트`를 선택하고 현재 페이지를 저장했다. 그룹·섹션 접기 후 `저장 위치 보기`가 경로를 다시 펼치고 링크에 초점을 준다.
3. **찾는 사용자**는 검색 결과가 없어도 쉽게 원래 목록으로 돌아가고 싶다. 0개 결과 안내와 복귀 버튼, Escape 검색 해제 통과.
4. **백업하는 사용자**는 현재 가능한 백업을 바로 찾고 싶다. 상단 `백업`이 JSON 영역을 열고 초점을 이동한다. 사용하지 않는 Google 버튼은 없고 초기화는 맨 아래에 둔다.
5. **복원하는 사용자**는 목록 교체를 미리 이해하고 실수 후 복구하고 싶다. 전체 교체 안내·개수 비교·사전 내보내기와 별도 안전 사본을 구현했다. 교체·동일 파일·편집 후 복구·저장 실패·지연 응답은 서비스 및 UI 함수 자동 테스트로 확인했다. **파일 선택부터 복구까지의 실제 브라우저 종단 흐름은 권한 제한으로 미검증**이다.

## 이번에 늘리지 않은 기능

Google 계정·자동 동기화·Drive 하위 폴더 조회·새로운 태그/중첩 단계는 추가하지 않았다. 현재 구조의 입력과 복구를 먼저 단순화했다. JSON 복원은 병합이 아닌 전체 교체이며, 이를 유지하되 비교·확인·안전 사본으로 위험을 낮췄다. 파일 선택 권한이 준비되면 실제 설치에서 복원 종단 검증이 다음 확인 항목이다.
