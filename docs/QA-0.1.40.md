# FAVMOA 0.1.40 · 대량 후보의 결과 전체 선택

검증일: 2026-09-25 KST. [개선 큐](USABILITY-IMPROVEMENT-QUEUE.md) 6번을 완료했다. 다음은 7번 가져오기 중 새 대상 그룹의 재현·범위 검토다. 실제 개인 탭·북마크·저장 데이터 대신 합성 자료로 검증했다.

## 재현과 결정

405개 탭 후보의 검색 결과를 더 보기 없이 전체 선택하는 회귀를 RED로 재현했다. 당시 버튼은 없었으며 기존 ‘보이는 항목 모두 선택’은 처음 200개만 골랐다. 조회 누락·선택 개수 제한·표시 범위 제한을 구분하기 위해 같은 조회 1회 상태에서 페이지 크기만 늘렸다. 200→400→405개 표시 후 선택 범위도 그대로 늘어 `shown`만 선택하는 계약임을 확인했다. 기존 계약은 유지하고 별도의 전체 결과 선택을 추가했다. diagnose·TDD의 재현→가설 확인→RED/GREEN과 독립 경계 검토를 적용했다.

첫 단축 동작을 통과시킨 뒤 숨은 1개 + 결과 1,000개를 합쳐 1,001개가 선택되는 별도 RED를 확인했다. 선택 전 합집합 크기를 검사해 전체 거부하는 방식으로 수정했다. 첫 1,000개를 임의 선택하거나 기존 숨은 선택을 제거하지 않는다.

## 구현 계약

- 준비·중복 제거·기저장 제외를 거친 후보의 **현재 필터 결과 전체**가 대상이다. 필터 없음은 ‘전체 N개 선택’, 필터 있음은 ‘검색 결과 전체 N개 선택’으로 표시한다. 후보 창의 문구 검색 방식은 변경하지 않는다.
- 결과가 현재 표시된 행보다 많을 때만 단축 버튼과 범위 설명을 표시한다. 표시 행은 200개씩 유지한다. 보이는 항목만 선택/해제하는 체크박스, 전체 선택 해제, 더 보기도 그대로 제공한다.
- 전체 결과는 기존 선택에 더하며 반복 클릭으로 해제하지 않는다. 검색 밖의 기존 선택도 보존한다. 합집합 1,000개까지 허용하고 초과 시 어떤 선택도 바꾸지 않으며 총 개수·제한·복구 방법을 안내한다.
- 선택 개수와 화면 밖 선택 개수, 결과/표시 개수와 범위 설명을 제공한다. 버튼은 native `button type=button`, 범위 설명은 `aria-describedby`로 연결한다. 버튼과 표시 체크박스를 재생성하지 않아 DOM 초점을 유지한다. 실제 스크린리더 발화나 네이티브 키보드 검증을 뜻하지 않는다.
- 단축 선택 자체는 저장하지 않는다. 별도 담기에서만 기존 `addLinks` 한 번으로 저장하고 목적지를 펼치며 단일 Undo로 복구한다. 로딩/저장/검토 중, 취소·대체된 창의 이전 버튼은 선택을 바꾸지 않는다.
- 충돌 뒤 최신 목록을 명시적으로 읽고 이미 저장된 후보를 제외한 결과 범위를 갱신한다. 원본을 재조회하거나 권한을 다시 요청하지 않으며 원래 선택 보존·목적지 검토·별도 담기 계약을 유지한다.
