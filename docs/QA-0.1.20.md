# FAVMOA 0.1.20 QA — 사용자 지정 테마

기록일: 2026-09-23 KST. 코드·합성 검증과 실제 Chrome 설치·사용자 데이터 확인을 구분한다.

## 변경 범위

- 사이드 패널 상단 **테마**에서 시스템 설정·밝게·어둡게 모드를 선택한다.
- 여섯 가지 색상 조합과 사용자 지정 강조색·밝은 배경·어두운 배경을 제공한다. 색상 선택기와 HEX 입력을 함께 제공한다.
- 미리보기는 임시 상태다. 저장하면 확정하고 취소·닫기는 저장 전 테마로 돌아간다. **기본 테마로**도 저장 전까지는 미리보기만 바꾼다.
- 배경과의 대비를 계산하여 글자·버튼·포커스 등의 표시 색을 정한다. 선택·현재 위치·오류는 색 외 표시도 유지한다.
- 테마는 Chrome 프로필별 별도 설정이며 링크 catalog·undo·복원 사본과 분리한다. 링크 JSON에는 포함하지 않는다. 목록 복원·목록 초기화는 테마를 바꾸지 않는다.
- 기존 재귀 그룹·일반 링크·로컬 저장·JSON 백업, 공개키·확장 ID·권한을 유지한다. Notion 콘텐츠 스크립트는 없고 Google 연동은 보류 상태다.

## 수용 기준

1. 처음에는 기본 테마가 적용되고, 시스템 모드는 기기 밝기 설정을 따른다. 명시적 밝게·어둡게 선택은 기기 설정과 독립적으로 유지된다.
2. 프리셋·색상 선택기·HEX 입력이 같은 초안 상태를 편집하고, 올바른 색만 저장된다. 잘못된 HEX에서 오류와 복구 방법을 알 수 있다.
3. 미리보기 취소·닫기 후 저장 전 설정으로 돌아간다. 저장 후 재열기에도 유지되고 저장 실패를 성공으로 표시하지 않는다.
4. 기본 테마 복원은 저장 전 미리보기다. 링크·그룹·undo·복원 사본·기존 Notion 자료를 변경하거나 삭제하지 않는다.
5. 링크 JSON 내보내기·복원과 목록 초기화는 테마 설정과 독립적이다. 테마를 다른 기기에 동기화한다고 안내하지 않는다.
6. 텍스트·버튼·포커스가 극단적인 사용자 색에서도 구분된다. 선택·오류를 색만으로 설명하지 않는다.
7. 키보드로 모드·색상·저장·취소에 접근하고, 좁은 패널과 확대 화면에서 주요 조작이 잘리지 않는다.
8. 공개키·확장 ID·기존 설치 경로·권한을 유지하며 Notion 전용 UI·Google 연결을 다시 활성화하지 않는다.

- 산출물: `artifacts/favmoa-v0.1.20.zip`, **34개 런타임 파일**, **170,704바이트**.
- SHA-256: `23cbf7ef5f62cb29f95574a0044b2a1661b81c45ba630c822ed64ece5b38d8de`.
- Chrome의 기존 등록 경로 `artifacts/favmoa-v0.1.13` 내용이 이전 0.1.19와 같음을 확인한 뒤 0.1.20로 교체했다. 경로 이름과 공개키 기반 ID `ebbgmhdbonpillbfjapebljagnbjembj`는 유지한다.
- 직전 프로그램은 `artifacts/favmoa-before-0.1.20-20260923`에 보존했다. **프로그램 파일 백업**이며 사용자 저장 데이터 백업이 아니다. 사용자 Chrome 프로필·인증 정보·저장소 파일을 직접 읽거나 변경하지 않았다.
- 관리 화면에서 **0.1.20 / Reloaded**를 확인했다. 테마 설정을 보려면 Chrome의 FAVMOA 아이콘으로 패널을 다시 열면 된다.
- 데모 색상 검사 후 UI의 **기본 테마로 → 저장**으로 데모 테마만 기본값으로 복원했다. 임시 브라우저 너비도 원래대로 돌렸다.

## 이번 범위가 아닌 후속 제안

그룹별 색상 표시, 고정·최근 링크 빠른 접근, 키보드 위치 이동 개선은 후속 제안이다. 이번 버전에서 구현·검증한 것으로 주장하지 않는다. 테마 클라우드 동기화·테마 파일 내보내기도 제공하지 않는다.

## 한계

- Node·합성 UI 검사는 모든 실제 Chrome 프로필·OS·디스플레이의 동작을 증명하지 않는다.
- 색 대비 계산 검사는 화면 전체의 WCAG 적합성 인증이나 실사용자 접근성 조사와 동일하지 않다.
- Notion 전용 메뉴·DOM 수집은 종료 상태이며, 실제 Google 로그인·Drive 백업·다른 PC 동기화는 이번 범위가 아니다.
